About the Random Team Generator

The Random Team Generator splits a list of people into groups at random. You choose either a number of teams or a team size, and it deals everyone into balanced teams, so no team is more than one person larger than another. It is useful for project groups, hackathons, workshop breakout rooms, sports and games, classroom activities and office events.

How it works

The tool sorts the names, shuffles them using a random sequence created from the draw code, and then deals them out one by one across the teams. Because the shuffle is based on the code, the same names with the same code always give the same teams. That is what makes a result checkable.

Can the organiser cheat?

A web page cannot stop an organiser from trying several draw codes until they like the result, and then sharing only that one. What the draw code does prevent is quiet edits: nobody can remove a name or swap two people without the result changing. To rule out code-shopping as well, do one of these:

1. Run the draw live on a shared screen or in a meeting, with everyone watching. 2. Agree the draw code in advance, for example a number each person suggests, added together. 3. Let someone who is not in the draw press the button, and share the code straight away.

Frequently asked questions

How are uneven numbers handled?

Teams differ by at most one person. For example, 10 people in 3 teams gives teams of 4, 3 and 3. With "People per team" set to 4, the tool uses 3 teams so that no team is larger than 4.

What does the verification link contain?

The names, the settings and the draw code, packed into the part of the address after the #. That part is never sent to any server, but anyone you give the link to can read the names, so share it only with your group.

Are my names stored anywhere?

No. EJD Tech has no server-side code or database. Your list exists only in the open page, or inside a link you choose to share.

Two people have the same name. What should I do?

Add a surname or initial, such as "Ravi K" and "Ravi S", so you can tell them apart in the result.

Can I redo the split?

Yes. Click "New code & re-draw" for a fresh random draw, or "Split into teams" to repeat the draw for the code currently shown.
