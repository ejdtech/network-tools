Free network tools for system administrators

EJD Tech Network Tools is a free collection of browser-based utilities for system administrators and network engineers. Find your public IP address, calculate IPv4 subnets and CIDR ranges, look up DNS records, generate strong random passwords and convert time between zones such as IST, UTC, EST and PST.

There is nothing to install and no sign-up. The tools run in your browser, and this site does not store the information you enter. More tools are being added one by one. Looking for something lighter? Try Office Fun for a spin-the-wheel and a random team splitter.
