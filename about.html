About Network Tools

Network Tools is a free, static collection of everyday utilities for network engineers and system administrators — public IP lookup, subnet calculation, DNS lookup and more.

Everything runs directly in your browser. This site does not use cookies, does not run any server-side code, and does not store or log anything you enter — most tools call free public APIs directly from your device.
