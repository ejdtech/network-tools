View SSL certificate details for a domain.

Coming soon — needs a small backend.

Reading a certificate's full details (issuer, expiry, chain) requires an actual TLS handshake, which browsers don't expose to JavaScript. Services like SSL Labs solve this with their own servers.

This can be added later with a small serverless function that performs the check and returns the result as JSON to this page.
