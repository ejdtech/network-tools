About the QR Code Generator

A QR code is a square barcode that a phone camera can read. This tool turns a link, a piece of text, Wi-Fi details, an email, a phone number or a contact card into a QR code you can download as a PNG image or a scalable SVG file. The code is generated in your browser by code that runs on this page. It does not use a third-party service, and what you type never leaves your device.

Handy uses for sysadmins and offices

Put a Wi-Fi QR code on the guest network sign so visitors can join without typing a password. Stick a code on a server rack or asset label that opens a documentation page or inventory record. Share a runbook, a status page or a ticket form on a poster. Print a contact card QR on a badge or handout.

Tips for a code that scans every time

Keep strong contrast: dark code on a light background is the safest. Very light colours, or light code on a dark background, fail on some scanners. Keep the quiet zone: the empty border around the code should be at least 4 modules wide. Pick the error correction level: Medium suits most uses, and High lets the code survive scratches or a small logo but makes it denser. Test before printing: scan the final code with at least two phones, at the size it will be printed. Shorter is easier: less text gives a simpler code that scans faster from further away.

Which format to download

Use PNG for documents, slides and web pages. Use SVG for printing and signs, because it stays sharp at any size. For large prints you can also choose the 2048 px image size.

Frequently asked questions

Does the QR code expire?

No. The code holds your data directly, so it works as long as the destination (such as a web page) still exists. There is no redirect service in between, and nobody tracks the scans.

Is it really free, and is my data private?

Yes. It is free to use, and EJD Tech has no server-side code or database. Everything you enter stays in the open page and is gone when you close or refresh it.

How do I make a Wi-Fi QR code?

Open the Wi-Fi tab, enter the network name and password, choose the security type (WPA covers WPA2 and WPA3), and download the code. On most phones, scanning it with the camera offers to join the network.

What is the maximum amount of text?

It depends on the error correction level. At Low, about 2,950 characters of plain text; at High, about 1,270. In practice, keep it much shorter so the code stays easy to scan.

Can I add a logo or change the colours?

You can change the code and background colours. Logos are not added by this tool. If you place a logo over a code yourself, use High error correction and test it carefully.
