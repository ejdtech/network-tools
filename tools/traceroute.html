Traceroute

See the path your packets take to a destination.

Coming soon — needs a small backend.

Real traceroute sends raw ICMP/UDP packets with increasing TTL values. Web browsers are not allowed to do this for security reasons, so a purely static site (like this one on GitHub Pages) cannot run a real traceroute.

To add this later, you'd deploy a tiny serverless function (e.g. a Cloudflare Worker or an AWS Lambda) that runs the traceroute on a real server and returns the result to this page as JSON — the rest of the site can stay exactly as it is.
