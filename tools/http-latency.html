HTTP Latency Check

Checks whether a web host responds and roughly how fast. This is not a real ICMP ping — browsers aren't allowed to send raw ICMP packets — it measures the round-trip time of an HTTPS request instead, which only works for web hosts (not arbitrary servers).

For true ICMP ping and traceroute, a static website isn't enough — that requires a small backend (see the Traceroute page for details).
