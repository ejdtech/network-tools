About the Password Generator

This tool creates random passwords of the length and character types you choose. The password is generated in your browser using the browser's secure random number generator (crypto.getRandomValues). It is never sent to any server, saved or logged.

What makes a password strong?

Length matters most. Each extra character multiplies the number of possible passwords. For most accounts, a random password of 16 characters or more is a good choice, and 20 or more suits important accounts. Using all four character types (uppercase, lowercase, numbers, symbols) increases the strength further.

Good habits

Use a different password for every account, store them in an approved password manager or vault, and turn on multi-factor authentication wherever it is offered.

How the strength bar works

The bar shows an estimate in bits, calculated as the password length multiplied by log2 of the number of characters available. It applies to randomly generated passwords like these, not to passwords chosen by a person.

Frequently asked questions

Is it safe to use an online password generator?

This one creates the password locally in your page and has no server-side code or database. For very sensitive or privileged accounts, such as production admin credentials, generate and store the password with your organisation's approved vault.

What does "exclude look-alikes" do?

It removes characters that are easy to confuse when reading or typing by hand: uppercase O, zero, lowercase l, one and uppercase I.

A system rejects my password. What can I do?

Some systems do not accept certain symbols. Untick "Symbols" and increase the length to keep the password strong.
