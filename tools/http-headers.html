HTTP Headers

View the response headers a website sends back. Browser security (CORS) limits what headers JavaScript is allowed to read from a different domain, so results can be partial unless the site opts in.

Only a small set of "safe" headers (like content-type) are visible to JavaScript across domains unless the target site sends an Access-Control-Expose-Headers header. For a complete header dump on any site, you'd normally run this check from a small backend instead of a browser — that can be added later without changing the rest of this site.
